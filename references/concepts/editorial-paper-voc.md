# Editorial Paper

Warm paper canvas (`#faf9f5`), ink type (`#101826`), narrative serif (Newsreader) for
findings and evidence quotes, Geist for UI. Status rides a four-regime quadrant
(voice × economics): Troubled red, Fragile amber, Healthy green, Latent blue —
each with glyph, tint and ink. Severity/defection read as warm heat chips
(`#FDEFE6 → #B93D16`) rather than cold color coding. Quiet cards (no accent bar,
hairline border, soft shadow); the rail is solid ink.

Source: VOC Redesign — Stores mockup (store case file + tiered heat leaderboard).
Use for executive VOC / decision surfaces where the finding should read as prose
first and the table should sort intervention to the top.
